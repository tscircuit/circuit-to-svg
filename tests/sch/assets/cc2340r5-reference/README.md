# Real CC2340R5 reference schematic

Source: [ShiboSoftwareDev/cc2340r5-reference-design 1.4.0](https://tscircuit.com/ShiboSoftwareDev/cc2340r5-reference-design/customize?package_release_id=bff7bbb1-c0df-4b3e-8cb2-5f5c706caa87&preview_file=dist%2Findex%2Fcircuit.json#schematic),
release `bff7bbb1-c0df-4b3e-8cb2-5f5c706caa87`.

Generated by the core companion [PR #5445](https://github.com/tscircuit/core/pull/5445),
using `tests/fixtures/cc2340r5-reference/export-circuit.tsx`. This JSON is actual
core output: 27 components, 16 original nets, and eight new GPIO nets.
The proposed module exports VDDS, GND, RESET_N, SWDIO, SWCLK, DIO8, DIO11,
DIO12, DIO13, DIO20_A11, DIO21_A10, DIO24_A7, and DIO6_A1. The eight GPIOs
were marked unconnected in the original board; their NC declarations are removed.
All 13 boundary terminals have routed wires to their real MCU pins. Core tests
verify the original electrical signature plus this explicit eight-net addition,
and traverse actual wire edges to check every exported terminal.
PCB records are omitted; schematic geometry is not postprocessed. JSON is
formatted with Biome after export.

The root wrapper replaces the original board and fixed A4 frame. All real
regulator, decoupling, RF/antenna, clock, reset, and SWD circuitry is retained at
the release's default settings. The sheet-selection test assigns this complete
schematic to a sheet alongside an empty cover sheet.

Regenerate from the core companion checkout:

```sh
bun tests/fixtures/cc2340r5-reference/export-circuit.tsx \
  ../circuit-to-svg/tests/sch/assets/cc2340r5-reference/circuit.json
bunx biome format --write ../circuit-to-svg/tests/sch/assets/cc2340r5-reference/circuit.json
```
